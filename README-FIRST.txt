PRIMESHOW ENTERTAINMENT — OFFICIAL GITHUB PAGES PACKAGE

Repository:
primeshowentertainment/primeshowentertainment.github.io

This package contains:
1. primeshow-entertainment/ — latest website source
2. .github/workflows/deploy-pages.yml — GitHub Pages build/deploy workflow

DO NOT upload this ZIP itself to GitHub.
Extract it first, then copy the CONTENTS of the PrimeShow-GitHub-Ready folder into the cloned repository.

Recommended upload method: GitHub Desktop.

After pushing to main:
GitHub repository > Settings > Pages > Build and deployment > Source > GitHub Actions

The workflow will build and deploy the website to:
https://primeshowentertainment.github.io/

After the GitHub URL is working, connect the .com domain in Settings > Pages > Custom domain.
